# デザインを変えるときの決まり（GPTに渡す）

この `site/` は **「ボートレース研究所」** の公開サイトです。すでに動いているものを直す形になります。
**見た目は自由に変えてよい**ですが、下の「壊すと困るもの」に触れると数字が出なくなったり、検索に出なくなったりします。

---

## 0. ファイルの構成

| ファイル | 何か | 変えてよいか |
|---|---|---|
| `index.html` | 外枠（ヘッダー・フッター・メニュー） | **見た目は自由** |
| `style.css` | 見た目のすべて | **全部自由** |
| `app.js` | 画面を組み立てる。データの読み込みもここ | **HTMLの組み立ては自由／データの読み方は触らない** |
| `config.js` | 接続先の設定 | **触らない**（運営が書き換えます） |
| `_redirects` `_headers` | 置き場の設定 | **触らない** |
| `ogp.png` | SNSに貼ったときの画像 | 差し替え可（1200×630） |
| `robots.txt` `sitemap.xml` | 検索エンジン向け。**自動で作られます** | **触らない**（手で直しても上書きされます） |
| `_local/` | 確認用のデータ。中身は本物 | **触らない** |

---

## 1. ページとURL

URLは **`#` を使わない実際のパス**です。リンクは必ず `href="/tenkai"` のように**スラッシュ始まり**で書いてください。

| URL | ページ |
|---|---|
| `/` | トップ（きょうのレース） |
| `/d/2026-09-23` | 別の日の出走表 |
| `/race/20260923-02-08` | レース詳細（末尾に `/odds` などタブ名が付く） |
| `/tenkai` `/tenkai/日付` | 展開予想の一覧 |
| `/news` `/news/<記事名>` `/news/tag/<タグ>` | ニュース |
| `/venues` `/venue/12` | 場の一覧・場の攻略 |
| `/racers` `/racers/all` `/racer/4320` | 選手 |
| `/schedule` `/meeting/<場>/<開始日>` | 開催予定 |
| `/analysis/average` ほか | データ分析 |
| `/results` | 的中実績 |
| `/member` | 会員（合言葉を入れる） |
| `/about` `/privacy` | このサイトについて・プライバシーポリシー |

### ⚠ ここを壊すと全ページが真っ白になります
- **`href` は必ず `/` 始まり**。`href="#/tenkai"` や `href="tenkai"` にしない
  （`#` 始まりだと検索エンジンから見て**サイト全体が1ページ**になります。相対パスだと `/race/…` を直接開いたとき読み込みに失敗します）
- **`index.html` の読み込みも絶対パス**：`/style.css` `/config.js` `/app.js`。頭のスラッシュを取らない
- `<main id="app">`・`<p id="updated">`・`data-nav="..."`・`<a class="skip" href="#app">` は残す

## 2. 壊すと困るもの（app.js の中）

### データの読み方
`doc('races/2026-09-23')` のような**鍵の名前**と、`e.win_probability`・`R.entries` のような**項目名**。
項目の意味は `API仕様.md` にあります。名前を変えると数字が消えます。

### 検索エンジン向けの処理
各ページに1回ある **`meta(題, 説明文, ...)`** の呼び出し。ページごとの題・説明文・canonical・OGP・構造化データを出しています。
**消さないでください。** 文言を良くするのは歓迎です。

### 見つからないページ
**`notFound()`**。知らないURLや消えたデータのときに「見つかりません」と検索避けを出します。
これを `home()` などに戻すと、打ち間違いのURLがぜんぶトップページとして検索に登録されます。

### 会員（合言葉）
`paidDoc()`・`openBox()`・`lockPanel()`。有料の中身は**暗号のまま置いてあり、合言葉で開いています**。
ここを触ると会員の方の画面が開かなくなります。見た目（`.lock` `.aipick` `.mem-form`）は自由です。

### 数字
`app.js` の中で**数字を作ったり、データに無い文章を足したりしないでください**。
「的中率」「回収率」「1着確率」はすべてデータから来ています。手で書くと事実と違うものが出ます。

---

## 3. 必ず残すもの

- フッターの注意書き4つ（20歳未満は購入不可／回収率は100%未満／実績は締切前に出した予想だけ／当サイトの集計値である旨）
- フッターの `.foot-nav`（このサイトについて・プライバシーポリシー・選手 全一覧・会員について）
- **枠番の色：1白・2黒・3赤・4青・5黄・6緑**（`.w1`〜`.w6`）。公式と同じにしてください
- 「本文へ移動」（`.skip`）・`aria-current`・表の左端固定（スマホ）

---

## 4. トップページの並び

`/` は上から **顔（`.hero`）→ 次の締切（`.next-race`）→ 日付タブ → きょうの無料予想（`.free-list`）→
きょうのレース → 注目レース・アラート → 本日の場状況 → ニュース → できること（`.entry-cards`）→ 会員の案内（`.member-cta`）**。

見た目は自由ですが、**この順番はスマホで「すぐ使うもの」が先に来るように決めています**。
入れ替えるときは「**締切が近いレースへ最短でたどり着けるか**」を確かめてください。

---

## 5. 載せてはいけないもの

- **有料の買い目**（3連複2点プランなど）。合言葉なしで見える場所には置かないでください
- 実績の数字を良く見せる加工（回収率は100%未満です。そのまま出してください）
- 「必ず当たる」「儲かる」といった表現

---

## 6. スマホ優先

**将来アプリにする前提**です。縦長・片手操作を最優先にしてください。

- 画面下のタブバー（`.tabbar`）＋「その他」メニュー（`.more`）
- レース詳細のタブは画面上部に貼り付け（`.tabs { position: sticky; top: 49px }`）
- 横に長い表は `.scroll` で囲み、**左端の列（選手名）は固定**
- 押すところは 44px 以上
- **横スクロールが出ないこと**（`document.documentElement.scrollWidth` が画面幅と同じ）

## 7. 明るい画面・暗い画面

色は `style.css` 先頭の `:root` の変数でまとめて変えられます。
暗い画面用は `@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の**両方**にあります。
**片方だけ変えると、どちらかで文字が読めなくなります。**

---

## 8. 直したら通すもの

渡していただければ運営側で流しますが、内容は知っておいてください。

```
node scripts/seo-audit.mjs      URLの作り・sitemap・ページごとの題・構造化データ・アクセス解析
node scripts/audit-public.mjs   有料の中身が公開側に混ざっていないか
```

どちらも「✗」が出たら公開できません。よく出るのは次の3つです。

| 出るもの | 原因 |
|---|---|
| ハッシュのリンクが残っている | `href="#/..."` を書いた |
| meta() の呼び出しが少ない | ページの題を出す処理を消した |
| 知らないURLでトップページを返している | `notFound()` を消した |

## 9. 確かめ方

運営側のPCで `site/` を開くと `_local/` の**本物のデータ**で表示されます。
変更したファイルを渡してもらえれば、こちらで表示と点検を確かめてから公開します。
