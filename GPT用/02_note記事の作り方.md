# note記事の作り方（1レース＝1記事）

## 1. 読むデータ

| 何に使う | URL |
|---|---|
| その日の2点プラン（記事にするレースの一覧と買い目） | `http://localhost:3940/plan2.json?date=YYYY-MM-DD` |
| 展開予想（本文の読みどころ） | `http://localhost:3940/api/v1/tenkai?date=YYYY-MM-DD` |
| 出走表（選手名・級別・勝率・モーター・平均ST） | `http://localhost:3940/api/v1/race?id=レースID` |
| 実績（記事末尾に載せる直近の成績） | `http://localhost:3940/api/v1/results?days=30` |

## 2. 作る前に必ず確かめること

1. `plan2.json` の `status` が `"ok"` か。**`"empty"` なら、その日は1本も作らずに終える**
2. 記事にするのは `closed` が `false`、`cancelled` が `false` のレースだけ
3. `generated_at`（予想を作った時刻）が今日の日付か。昨日以前なら作らない

## 3. 記事の組み立て（1レース分）

**タイトル**：`【{venue}{race_no}R】{deadline}締切｜3連複2点プラン`
（例：`【多摩川12R】16:30締切｜3連複2点プラン`）

**無料部分（誰でも読める）**
1. レースの紹介：`venue`・`race_no`・`deadline`・`series`・`day_no`日目
2. 出走表：6艇の `name`・`class`・`win_rate_national`・`motor_top2_rate`・`avg_st`（表にする）
3. 展開予想：`tenkai.summary` をもとに2〜4文。`shape`（イン逃げ濃厚／混戦 など）を見出しにする
   - 本線 `honmei`・対抗 `taiko` の名前・決まり手・確率はデータのまま書く
   - `start` が「速い」なら「スタートが速い」と書いてよい。それ以外の想像は書かない
4. 注意書き（下の6.）

**有料部分（ここから下を有料にする）**
5. 買い目：`races[].trio` の2点（`combo` と `probability`）
6. 1レース200円であること

**書いてはいけないこと**
- データに無い情報（選手の調子、前日のコメント、天気の予想など）
- 「鉄板」「絶対」「儲かる」など、当たることや利益を約束する言葉
- 確率・的中率を丸めたり、足し算して新しい数字を作ったりすること

## 4. 画像

- 1記事に1枚。**レース名・締切・展開の型（`shape`）・本線と対抗の枠番と名前**を入れる
- 枠番の色は公式と同じにする：1白・2黒・3赤・4青・5黄・6緑
- **買い目（有料部分）は画像に入れない**（画像は無料で見えるため）
- 実在のボートレース公式のロゴや写真は使わない

## 5. 投稿のタイミング

- 締切の30分以上前に投稿する。締切まで30分を切ったレースは作らない
- 同じレースを2回投稿しない（`race_id` で確かめる）

## 6. 記事の末尾に必ず入れる文

> この予想は的中を優先したものです。回収率は100%未満で、買い続けると資金は減ります。
> 過去の実測（学習に使っていない175日・2,689レース）では、3連複2点の的中率は58.9%でした。
> 舟券の購入は20歳からです。

実績を載せるときは `/api/v1/results` の `total.plan2`（`hit_rate`・`return_rate`・`races`）をそのまま書き、「直近30日・締切前に出した予想だけを集計」と添える。
