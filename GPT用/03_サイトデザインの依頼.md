# データサイトのデザイン依頼（将来はアプリ）

## 1. どんなサイトか

- 名前（仮）：**凪の予想配信**（ドメイン・正式名は未定）
- 中身：競艇（ボートレース）の出走表・選手・場のデータと、AIの1着確率・展開予想・実績
- お金の流れ：買い目（3連複2点プラン）は **noteで販売**（1レース200円・月額1000円）。サイトは無料のデータで人を集め、noteへ案内する
- **将来アプリにする予定**。スマホで見やすいこと（縦長・片手操作）を最優先。ページの作りは、そのままアプリの画面になる前提で考える

## 2. 作るページと使うデータ

| ページ | 使うURL | 載せるもの |
|---|---|---|
| トップ（きょうのレース） | `/api/v1/races?date=` | 場ごとにレースを並べる。締切・開催名・本命（`favorite`）・結果。締切が近い順にも並べ替えられるように |
| レース詳細 | `/api/v1/race?id=` | 出走表6艇（`entries`）・1着確率の棒グラフ（`win_probability`）・展開予想（`tenkai`）・結果（`result`）。**`prediction` と `picks` は出さない**（有料）。代わりに「このレースの買い目はnoteで」ボタン（`has_paid_picks` が true のときだけ） |
| 展開予想一覧 | `/api/v1/tenkai?date=` | 全レースの `shape`・本線・対抗・決まり手の上位3つ |
| 実績 | `/api/v1/results?days=30` | 商品ごとの的中率・回収率・日別の表。**外れた日も同じ表に並べる** |
| 選手 | `/api/v1/racer?id=` | プロフィール・コース別成績（`by_course`）・勝ち方（`winning_moves`）・直近20走（`recent`） |
| 場 | `/api/v1/venue?jcd=` | コース別1着率・決まり手・1コースの月別/レース番号別の強さ・3連単の平均配当と万舟率 |
| このサイトについて | なし | データの作り方・注意書き（下の4.） |

会員向け（有料）ページは今は作らない。作るときに `picks` を使う。

## 3. デザインの決まり

- 枠番の色は公式と同じ：**1白・2黒・3赤・4青・5黄・6緑**（文字色は白・黒の読みやすい方）
- 級別（A1・A2・B1・B2）はバッジで色分け
- 確率は `%` 表記。数字は等幅にしてそろえる
- 「締切済み」「中止・順延」「結果」は、色だけでなく文字でも分かるようにする
- 公式サイトの文章・画像・ロゴは使わない（データの数字はこちらで集計したもの）
- 暗い画面（ダークモード）にも対応

## 4. 必ず載せる注意書き

- 回収率は100%未満です。予想は的中を優先したもので、利益を約束するものではありません
- 実績は、締切前に出した予想だけを集計しています（外れた日も含みます）
- 平均ST・F回数・コース別成績は公式の値ではなく、出走履歴から当サイトが集計した参考値です
- 舟券の購入は20歳からです
- データの誤りについて責任を負いかねます。正式な情報は公式サイトで確認してください

## 5. アプリ化のときの前提

- データは同じURL（`/api/v1/...`）から読む。アプリ専用の窓口は作らない
- 画面は「トップ → レース詳細 → 選手／場」の3階層を基本にする
- 有料の買い目を見せる画面は、会員の確認（ログイン・購入の確認）ができてから作る
