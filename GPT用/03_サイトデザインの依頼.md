# サイトのデザイン変更の依頼（将来はアプリ）

## ⚠ まず知っておくこと（2026-09-23 更新）

**サイトはもう出来上がっていて、動いています。** ゼロから作るのではなく、**あるものの見た目を直す**仕事です。

- 実物のファイル一式：`競艇予想\site\`（`index.html` / `style.css` / `app.js` / `config.js`）
- **必ず先に読むもの：`site\デザイン変更の決まり.md`**
  どのファイルを触ってよいか、何を壊すと画面が真っ白になるか、必ず残す表記は何かが書いてあります
- 確認用の本物のデータが `site\_local\` に入っているので、運営側のPCで開けばそのまま表示されます

このファイル（03）は**全体像**です。細かい決まりは「デザイン変更の決まり.md」が正です。食い違ったらそちらに従ってください。

## 1. どんなサイトか

- 名前：**ボートレース研究所**（ドメインは取得予定）
- 中身：競艇（ボートレース）の出走表・選手・場のデータと、AIの1着確率・展開予想・実績
- **将来アプリにする予定**。スマホで見やすいこと（縦長・片手操作）を最優先。ページの作りは、そのままアプリの画面になる前提で考える

## 2. ページとURL

URLは **`#` を使わない実際のパス**です（`/tenkai` など）。一覧は「デザイン変更の決まり.md」の §1 にあります。

| ページ | 載せるもの |
|---|---|
| **トップ `/`** | 顔・次の締切・きょうの無料予想・きょうのレース・注目レース・アラート・場状況・ニュース・できること・会員の案内 |
| レース詳細 `/race/<id>` | 出走表10タブ（出走表／基本情報／枠別情報／モータ／今節／直前情報／オッズ／展開予想／出目／結果） |

## 3. 出走表に出す数字（2026-09-23 に増えました）

公式のHTML出走表から取れるようになったので、**3連対率**と**公式の平均ST・F/L**が使えます。

| 項目名 | 中身 |
|---|---|
| `win_rate_national` `top2_rate_national` `top3_rate_national` | 全国 勝率・2連対率・**3連対率** |
| `win_rate_local` `top2_rate_local` `top3_rate_local` | 当地 同上 |
| `motor_top2_rate` `motor_top3_rate` / `boat_top2_rate` `boat_top3_rate` | モーター・ボート |
| `avg_st` `avg_st_source` | 平均ST。`avg_st_source` が `"official"` なら公式の値 |
| `f_count` `l_count` | F・L回数（公式） |
| `win_probability` | **AIの1着確率**（当サイトの予想） |

**公式の値と当サイトの集計値は混ぜないでください。**フッターで書き分けています。

## 4. 必ず載せる注意書き

- **舟券の購入は20歳からです**（モーターボート競走法第12条）
- 予想は的中を優先したもので、利益を約束するものではありません。**回収率は100%未満です**
- 実績は締切前に出した予想だけを集計しています（外れた日も含みます）
- 出走表の勝率・2連対率・3連対率・平均ST・F/Lは公式の値。コース別成績・場別成績・展開予想などは当サイトの集計

## 5. やってはいけないこと

- **数字を作らない。**確率・的中率・回収率・配当は、データにある値だけをそのまま使う
- **有料の買い目を合言葉なしで見える場所に出さない**
- 「必ず当たる」「儲かる」と書かない。当たった日だけを切り取らない
- `app.js` のデータの読み方（鍵の名前・項目名）と、`meta()`・`notFound()`・会員まわりの処理を消さない

## 6. 直したあと

運営側で次の2つを通してから公開します。どちらかで「✗」が出たら公開できません。

```
node scripts/seo-audit.mjs      URLの作り・ページごとの題・構造化データ・アクセス解析
node scripts/audit-public.mjs   有料の中身が公開側に混ざっていないか
```

よく出る失敗は「`href="#/..."` と書いた」「`meta()` を消した」「`notFound()` を消した」の3つです。
