# 凪の予想配信 ― GPTに渡す資料一式

このフォルダは、GPTに **①note記事の自動生成** と **②データサイトのデザイン**（将来は③アプリ）を任せるための資料です。
GPTには、このフォルダの中身をすべて読み込ませてから作業を始めさせてください。

## 入っているもの

| ファイル | 中身 | 使う場面 |
|---|---|---|
| `00_はじめに読む.md` | この案内と、どの作業でも守るルール | すべて |
| `01_API仕様.md` | データの窓口（URL）と、各項目の意味 | すべて |
| `02_note記事の作り方.md` | 1レースごとの記事と画像の作り方 | ① note記事 |
| `03_サイトデザインの依頼.md` | 作るページ・各ページに使うデータ・必ず載せる注意書き | ② サイト ／ ③ アプリ |
| `data/` | **本物のデータの見本**（作成日のもの）。形を確かめるために使う | すべて |

`data/` の見本は作成した日のスナップショットです。**記事やページに載せる数字は、必ずその日のURLから取り直してください。** 見本の数字を使い回してはいけません。

## どの作業でも守るルール（必須）

1. **数字を作らない。** 確率・的中率・回収率・配当・選手の成績は、データにある値だけをそのまま使う。丸めたり、推測で補ったりしない。データに無いこと（選手の調子・モーターの評判など）を事実のように書かない。
2. **予想が無い日は何も作らない。** データの `status` が `"empty"` のときは、記事もページも作らない。
3. **締切済みのレースは記事にしない。** `closed` が `true` のレースは、これから買う人向けの記事にしない。
4. **有料の中身を無料で出さない。** `access` が `"paid"` の項目（`prediction`・`picks`・`/plan2.json`）は、noteで販売している買い目（1レース200円・月額1000円）。無料のページや記事の無料部分に載せない。
5. **儲かると言わない。** 回収率は100%未満です（買い続けると減る）。「必ず当たる」「儲かる」「回収率○○%保証」などは書かない。当たった日だけを切り取って見せない。
6. **実績と検証値を混ぜない。** 実績（実際に出した予想の成績）と、長期の検証値（学習に使っていない175日・2,689レースの実測）は、別のものとして書く。
7. **20歳未満は買えない。** 舟券の購入は20歳から（モーターボート競走法第12条）。記事・サイトに必ず載せる。

## データの取り方

- このPC：`http://localhost:3940/api/v1`（一覧が返る）
- 同じWi-Fiのスマホ等：`http://<PCのIPアドレス>:3940/api/v1`
- 今はPCの中（と同じWi-Fi）からしか見えません。公開サイトにするときは、公開先に合わせて出し方を別に決めます。

## 用語

| 用語 | 意味 |
|---|---|
| 3連複2点プラン | 1レースで3連複を2点だけ買う商品（200円）。noteで販売 |
| 配信（4点） | 3連複4点＋3連単4点 |
| 無料枠 | 1着確率80%以上の本命を単勝1点で出す無料公開分 |
| 自信度 | 3連複の上位4点の確率の合計（%）。76以上のレースだけを配信・2点プランに出している |
| 展開予想 | 1着確率と、枠ごとの決まり手の実測（直近1年）から作った「どう決まりそうか」 |
| 後出し | 締切後に記録された予想。実績から外してあり、データにも出てこない |
